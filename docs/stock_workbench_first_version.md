# 个股行情与算法买卖参考 · 第一版

输入名称或六位代码，点击任意A股，进入原主页面的个股详情。详情顶部显示报价、原报价时间、来源与采集时间，以及本地算法的买入确认参考位、止损/退出观察线、止盈观察位、理由和有效期。

行情来自既有报价源；计算在本地，不需要模型。默认只读缓存。启用“自动报价”是显式联网选择；只获取正在查看的股票，盘中约15秒一次，切换或关闭详情停止原股票刷新。休市不自动请求报价源；页面隐藏时暂停请求。

实时刷新只更新进程内存，最多64只缓存、一次请求在途、至少10秒请求间隔。它不更新正式日线、盘中归档、账本、报表或任务，不产生订单。GET不能通过query参数开启联网；POST沿原同源校验和显式网络意图。默认网络/LLM开关不变。

## 买卖参考的来源

本版不增加策略、不改变权重或原公式。复用现有日线情景：

- 买入确认参考位：原进攻情景上沿，即60日收盘高位与5日历史波动上沿的较小值；
- 止损/退出观察线：原失效情景下沿，即60日收盘低位与5日历史波动下沿的较大值；
- 止盈观察位：原5日历史波动上沿。若未高于买入参考位则显示缺失并提示观望，不编造正向空间。

原进攻与失效条件、趋势理由和均线量能说明原样消费。盘中触及买入参考位仍需收盘与量能确认，不冒充完整日线信号。有效期使用已保存交易日历中的下一交易日收盘；日历缺失、日线陈旧或到期时保留历史参考标签，不宣称当前信号。

原始整份日线先执行price_data_contract分类及一致性校验，再过滤未完成日期、排序和去重。只用明确raw日线产生可与raw报价比较的参考价；混合、未知、复权日线不直接转换成实时报价参考。未来qfq信号/raw成交桥接仍未实现。

## 数据异常

报价没有日期时不借用今天、采集日期或文件时间。报价时间晚于当前/采集时间、证券不匹配、来源未记、价格无效、盘中陈旧等均显示告警。报价口径未核实不与日线参考价比较。报价更新失败保留原较新记录及时间。

报价请求返回后重新核验时刻，不以请求前的时刻误判正常的新报价。进程内存和正式保存缓存都按有效的原报价时间比较，较新的保存快照不会被旧内存覆盖。交易日历未覆盖当前日期、日线读取或算法计算失败时分别降级并提示，仍可查看独立报价；不会让整条个股接口报500。排除的未完成日线在页面显示警告。

历史不足60条时只显示报价和缺失原因；不足20条导致旧详情无法画图，也保留顶部报价与参考状态。成交量/额的单位未记录时明确提示，不把手和股混用。

所有参考标记“纸面 · 未验证”。没有样本外验证的盈利结论，不更改已有策略账或AI账。
