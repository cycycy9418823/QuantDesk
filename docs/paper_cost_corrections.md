# 纸面策略账成本更正候选

服务于宪章 §2、§4 和 §12 第19条。当前是候选，未安装、未接受。

加仓后的浮动盈亏和今后平仓盈亏使用已记录的 `avg_cost`；旧记录缺少有效均价时保留入场成本回退。卖出触发仍使用原来的入场价格，成交条件、成交价格、现金、费用、策略参数保持原样。

旧平仓原件不改。只对记录字段能够逐分解释的入场成本冲突新增 `realized_corrections`：每条指向原件的规范摘要、原 JSON 字节和观察时间；保存原金额、新金额及差额。原 `legacy_realized_adjustment` 保留，生效的合计是底数加上已核验的更正。重复标识、重复原件、金额不符、原件不符、证据缺失或无时区时间会使更正无效。

所有共同读者使用同一核验：账本归并、策略摘要、展示投影、盈亏审计和新鲜度检查。坏更正不能因顶层余额恰好相等而变为已核对。更正后的展示保留旧平仓金额，并显示有效金额；完整历史现金流、公司行动和收益表现仍各自等待证据。

离线预览默认只读，显式指定新的项目外目录才保存可审查材料：

```powershell
python -B scripts/prepare_paper_cost_corrections.py --state <策略账原件路径>
python -B scripts/prepare_paper_cost_corrections.py --state <策略账原件路径> --output-dir <项目外新预览目录>
```

输出包括逐字节原件、候选账本和 `preview.json`。候选保留旧平仓、减仓和动作数组的原 JSON 字节；预览拒绝覆盖已有目录或写入输入项目。输入在读取和计算期间变化会使预览失效。这里没有安装入口，不运行行情、模型、通知或计划任务。

正式安装须由所有者明确指定实施者及源码/策略账写入范围，按既定早报核对后的窗口串行处理。先验证自然任务空闲、现有 OS 锁和受保护文件摘要；以最新账本重新预览，原件摘要必须与本次批准材料一致。源码和只增更正须同批应用、核对各处有效合计，然后才观察下次自然复盘。不能只装均价计算而遗漏旧平仓更正。

回退材料是同批源码前件和逐字节账本前件。原件摘要仍一致且没有后续业务写入时，恢复前件；已有后续业务写入时先停止回退并报告，不能用旧备份覆盖新动作。运行文件仅留项目外备份，不提交或导出到源码。
