# 卖法研究表的计算口径

服务于宪章 §2、§4、§8。只研究既有策略账的入场，不修改选股、卖法、账本、行情、模型、推送或计划任务。方法号 `exit-replay-v2-20261103`，每份 JSON 保存方法、参数摘要、源码 SHA 和输入文件 SHA。

## 怎么用

```powershell
python -B -X utf8 scripts/run_exit_rule_replay.py --root <真实资料目录> --as-of 2026-11-02 --output-dir D:/QuantDesk_research
```

`--output-dir` 明确指定研究报告位置。输出同名 Markdown/JSON；状态 `research_partial` 表示能算研究对照，但公司行动等条件尚未完整核清，永远不意味着正式策略已验证。`blocked` 返回码 2，报告说明缺什么，不保留本次收益、回撤等指标冒充成功。

每周第一个交易日，既有早报程序在资料业务日期核对后调用同一函数，用上个交易日截止的数据更新研究表。无需增加计划任务、网络或模型。研究表更新失败时早报正文继续生成，并明确写“旧表不能代表本次结果”。这段接线的自然效果须在代码正式应用后核对。

## 表里几个不同问题

| 部分 | 计算什么 | 如何避免误读 |
|---|---|---|
| 目标持有5/10/20个交易日 | 已完成窗口的股价变化、费用拖累、扣费后收益、同期间指数变化 | 未满期限单列。到期跌停等不能卖则延后到首个可卖收盘；同时列实际平均持有天数和延期笔数。 |
| 同一批成熟样本 | 5、10、20日都已结束且数据可核实的共同交易 | 不将不同入场批次的两个均值直接相比。 |
| 卖法研究持仓池 | 同一批各方案都可重放的入场，已平仓盈亏加未平仓日估值 | 每笔100股、10万元起始资本，是虚拟研究池，不是原策略账，不复原加仓和旧现金流。 |
| 同一天卖的收盘/开盘比较 | 同一批交易、相同退出日期，仅改变买入价格及相应费用 | 不拿早期盘中成交价冒充信号收盘价；不能按信号收盘买入的股票也明确列出。 |
| 开盘后再拿10天 | 入场价、入场日和退出日一起变化的整个政策 | 明确列配对数和退出日改变的笔数，不当成单纯买价影响。 |
| 均线偏离分组 | 入场时≤5%、5%–10%、>10%的历史/新样本结果 | 这是观察性猜想，不能从组间差异宣布因果或修改策略。 |

## 价格、成本和可成交

- 完整原始股票文件在日期过滤、排序、计算前调用项目的价格合同分类/校验。未知、混合和非 raw 口径不能计算这个成交重放；一个请求中的不可信股票不能静默排除后制造完整成功。
- 沪深300读作指数点位，单独作为基准，不冒充股票原始成交价。次日开盘买入时，暴露期间的基准也从次日指数开盘点位开始；另留信号日起的基准。
- `execution_price` 缺失时，不用已含买入费用的 `entry_price` 代替。原件及原因单列，其他可计算交易仍是局部研究结果。
- 费用调用统一费用服务，显式使用 `cn_current`：佣金每边万2.5/最低5元、卖出印花税0.05%、双边过户费0.001%、研究滑点为0。既有账本的默认费用参数不变。未平仓只扣买入费用；预计清算卖费另列，不当成已发生费用。
- 原始 OHLCV、前收、按日期的涨跌停规则用于可成交检查。零成交、缺开盘/高低价、涨停买入、跌停卖出均不给成交。当前名称不证明历史ST身份，使用保守未知ST口径；除权筛查不代表公司行动已完整核对。
- 目标持有日按已有本地市场日历计算，不按某只股票已有几行数据计算。日历缺失只能明确标指数日期代理；缺股票某交易日的数据不能当作停牌，更不能补造价格。

## 每日回撤

每日净值 = 现金 + 当日真实持仓估值，包含未平仓浮亏，保留资金占用。缺日估值就留空；资金检查保守按同日先买后卖，不能借后来的卖款完成之前的买入。现金出现负数时，说明这批固定100股入场用10万元无法保证完成，回撤字段留空并写具体缺口。

退出日期累加已实现盈亏没有每日浮亏/资金信息，因此不再称作最大回撤。研究池净值不冒充实际策略账净值。

## 新样本协议

规则和分组在2026-11-03收盘前封存，未来初次入场从11/3起单独计数。每次报告带 `protocol_sha256`，便于核对有没有事后改口径。股票选择本身仍由既有策略决定；少样本、重叠持仓和市场环境差异仍在。

如果11/3有新入场，目标5、10、20个交易日分别在11/10、11/17、12/1到期；到期缺资料或不可卖时明确标记。每周更新只使用已经出现的资料，不提前补结果。不能保证这些日期有足够样本，更不能把历史平均当成上周账本的假想收益。

## 验证与退回

定向回归覆盖：未成熟样本分开、费用仅计一次、未知口径在清理日期前拒收、按日历计数、缺日/涨跌停不造成交、配对比较、未平仓日净值回撤、资金不足留空，以及周研究失败仍生成早报正文。

正常隔离验收现在也保留两份明确维护文件：`docs/screenshots/README.md`、`build/QuantDesk.spec`；只复制存在且非符号链接、位于源目录内、各不超过2MB的原件。其他忽略文件不扩大复制范围。行情、账本和私密配置仍不属于源码副本；复制内容与清单SHA使用同一份读取字节。

修复从当前正式六文件逐 SHA 原件接续；仓外 `SOURCE_BASELINE.json` 和 `before/` 保留原件。候选退回仅恢复本批六个原有文件，移除本批两份新增测试/说明，不能覆盖其他任务改动。正式应用、集成验收与真实自然运行是独立记录，不用隔离测试代签。
