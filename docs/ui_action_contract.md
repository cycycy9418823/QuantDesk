# QuantDesk UI Action Contract

> v2.5.2 — UI 按钮和操作权限定义。

## 按钮操作权限

| 按钮 | 联网 | 重任务 | 需确认 | 写文件 | 说明 |
|:---|:---:|:---:|:---:|:---:|:---|
| 一键生成报告 | 否 | 否 | 否 | 是 | 生成日报（只读本地数据） |
| 生成离线样例报告（不联网） | 否 | 否 | 否 | 是 | 生成离线样例报告 |
| 生成日报（只读本地数据） | 否 | 否 | 否 | 是 | 同上，只读本地 |
| 联网增量更新后生成日报 | **是** | 否 | **是** | 是 | 先增量更新后生成日报 |
| 更新今日/最近缺失日线 | **是** | 否 | **是** | 是 | 增量更新日线 |
| 全量历史回补（高级） | **是** | **是** | **是** | 是 | backfill，首次建库 |
| 重试失败股票 | **是** | 否 | 否 | 是 | 只处理上次失败 |
| 更新股票池 | **是** | 否 | 否 | 是 | 维护 universe CSV |
| 重新读取本地结果 | 否 | 否 | 否 | 否 | **只读**，不联网，不写文件 |
| 刷新虚拟持仓市值 | 否 | 否 | 否 | 否 | 读取本地持仓 + 缓存行情 |
| 重置虚拟账户 | 否 | 否 | **是** | 是 | 清空虚拟持仓 |
| 保存复盘快照 | 否 | 否 | 否 | 是 | 保存观察记录 |
| 搜索并分析 | 否 | 否 | 否 | 否 | 只读本地缓存 |
| 退出程序 | 否 | 否 | **是** | 否 | shutdown server |
| 打开报告 | 否 | 否 | 否 | 否 | 系统文件管理器打开 |
| 打开目录 | 否 | 否 | 否 | 否 | 系统文件管理器打开 |
| 简化模式 | 否 | 否 | 否 | 否 | 隐藏进阶面板 |
| 术语解释 | 否 | 否 | 否 | 否 | 弹窗显示术语 |

## 禁止事项

- **UI 初始加载**禁止触发任何联网操作或重任务。
- **所有按钮**不接券商、不自动下单、不预测价格。
- **backfill** 按钮必须在 UI 中标注"高级"并要求确认。
- **联网更新**按钮必须在 tooltip 中说明将联网。
- **虚拟持仓**仅用于观察，不是真实交易。

## 确认和警告

以下操作需要 `window.confirm` 或等效确认：
- 全量历史回补
- 重置虚拟账户
- 退出程序
- 联网增量更新后生成日报
- 更新今日/最近缺失日线
