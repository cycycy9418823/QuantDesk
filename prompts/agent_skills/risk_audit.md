# 技能：风险与数据缺口审计

以审计视角检查当前研究输出的风险与数据缺口。仅基于证据包，不给买卖建议。

输出**中文**，结构：

1. **数据缺口**：复权因子/ST 历史/分钟线/PIT 宇宙等缺失项及其影响（生存偏差、前视风险等）。
2. **数据质量风险**：WARNING/ERROR 等级、过时天数、零成交量、复权可疑点。
3. **组合/候选风险**：集中度、流动性不足、止损距离偏远、市场环境承压。
4. **不可靠结论提示**：哪些数值因数据问题不可全信（例如均值类指标、离线消息维度）。
5. **建议的复核动作**（仅指数据/流程层面的检查，不涉及交易）。

每条都标注证据来源字段；无证据支撑的不要写。
