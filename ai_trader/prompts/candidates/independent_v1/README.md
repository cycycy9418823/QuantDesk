# 独立菜单候选 v2.0.0-candidate.1

状态：离线候选，未获 §4 行为验收；不替换活动 v1.0.0 文件，不改默认配置、定时任务或信任级别。

目的：去掉研究台推荐、规则排行/样本外表现与策略证据提示，逐项明确模型来源与事前验证条件。候选仍只观察有上限的本地股票样本，不能称为全 A 独立扫描。显式 `run_evening(prompt_candidate="independent_v1", ...)` 才选择候选；活动调用不传该参数。

离线比较入口：`python -m ai_trader compare-prompts --context-json <本地合成或已脱敏上下文.json> --out-dir <独立输出目录>`。它只生成两个渲染后的提示词、内容哈希与差异清单，不调用模型、不联网、不读写账本。测试用合成候选和确定性回复验证来源隔离、条件传递、空仓/持仓以及失败 hold 路径。

行为差异：候选模型明确选择的买入不依赖规则方法已通过；模型未要求的卖出不由规则补入；成交/仓位约束保持原样。此差异只在显式候选生效，活动默认仍保持既有成功模型路径，并逐项如实标识其中的规则卖出。

§4 仍缺：真实可复核历史基线、冻结样本外窗口、事前验收指标及用户批准。离线结构比较和合成回归不能证明真实收益、独立判断质量或样本外优势。完成这些条件前，不应切换活动菜单。
